# Hi, I'm Prem Poddar

I build apps for Android, iOS, macOS and the web, and the odd bit of hardware too.

**All my work lives on [prempoddar.is-a.dev](https://prempoddar.is-a.dev)** — every app with its write-up, my client work, how-it-works posts, and a toolbox of things I recommend.

## Apps

- **[CaffeinateCat](https://prempoddar.is-a.dev/apps/caffeinatecat/)** - keeps a Mac awake, even with the lid closed
- **[Brewlight](https://prempoddar.is-a.dev/apps/brewlight/)** - Spotlight, but for Homebrew
- **[Duet](https://prempoddar.is-a.dev/apps/duet/)** - listen to music together, in sync, no account
- **[OAF](https://prempoddar.is-a.dev/apps/oaf/)** - open and edit almost any file on Android
- **[Loadstone](https://prempoddar.is-a.dev/apps/loadstone/)** - save a spot, one arrow walks you back
- **[LibreChat](https://prempoddar.is-a.dev/apps/librechat/)** - encrypted messaging over Bluetooth, no internet
- **[Campfire](https://prempoddar.is-a.dev/apps/campfire/)** - a chat room for everyone nearby, hosted by one phone
- **[Tune](https://github.com/PremPoddar/Tune)** - per-app volume mixer for Android
